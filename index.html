CloveRTLS

当前 Windows x64 版本：0.0.1.5

下载安装程序（可选择安装目录） · 查看全部安装包、ZIP 和校验值

推荐下载 setup.exe，按向导选择当前用户可写的安装目录。支持应用内下载的版本可通过“帮助 → 检查更新 → 下载并退出更新”下载并校验安装包，启动向导后退出应用，更新到原目录；旧客户端首次需要手动运行新版安装包。

MSIX 安装与自动更新清单（安装位置由 Windows 管理）

下载后双击 .appinstaller 完成安装，Windows 将按策略检查后续更新。已经安装旧版 MSIX 的用户也需要通过清单更新一次，以关联更新地址。

更新前请保存工作并通过托盘退出应用。使用测试证书时，请先确认来源并手动信任发行版附带的公钥证书；企业策略可能限制安装。

ZIP 免安装版需要完整解压后运行 clovertls.exe，不参与 MSIX 自动更新。
