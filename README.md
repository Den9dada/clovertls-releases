# CloveRTLS Windows

[下载发行版](https://github.com/Den9dada/clovertls-releases/releases)

- 安装版：下载 `*-setup.exe`，按向导安装。
- 免安装版：完整解压 ZIP 后运行 `clovertls.exe`。
- MSIX：通过 [CloveRTLS.appinstaller](https://den9dada.github.io/clovertls-releases/CloveRTLS.appinstaller) 安装；使用自签证书时须先信任发行版附带的 `CloveRTLS-signing.cer`。

校验值见发行版附件 `SHA256SUMS.txt`。更新前请保存工作并退出应用。
